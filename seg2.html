二、方法：llm-sunset，一次扫完整个仓库

GitHub 上有个 MIT 开源小工具 llm-sunset（Ashveil1/llm-sunset，地址：https://github.com/ashveil1/llm-sunset），专门干这件事：扫描你的代码，找出所有 AI 模型 ID，再跟一份每日更新的官方退役公告数据做比对，告诉你哪些要退役、还剩几天、官方建议换成什么。

它有几个讨巧的设计：

零依赖，纯 Python 标准库，Python 3.8+ 就能跑；pipx run llm-sunset 连安装都省了。

可离线：自带每周刷新的快照，联网时用实时数据。

覆盖面广：OpenAI、Anthropic、Google Gemini、Groq、Cohere、xAI。

CI 友好：有 GitHub Action、pre-commit hook，还能输出 SARIF 接 GitHub 代码扫描；--fail-within 90 让 90 天内退役的模型直接让流水线变红。

低误报：精确匹配模型 ID（gpt-4o-mini 不会被当成 gpt-4o）；像 command 这种通用短词，只在 model: 这类上下文旁边才算数。

常用命令就几条：llm-sunset 扫当前目录，llm-sunset info o1 查单个模型，llm-sunset upcoming --days 90 列未来 90 天所有退役，llm-sunset fix --dry-run 预览自动替换，llm-sunset baseline 写基线只报新增。
