四、验收动作：今天就把这 5 步做了

  1. 今天跑一遍：pipx run llm-sunset（或 pip install llm-sunset），在你所有仓库根目录各扫一次。
  2. 接到 CI 里：加上 GitHub Action，fail-within 设 60 或 90，让未来的退役公告自动变成流水线红灯，而不是线上事故。
  3. 按表替换：对照官方建议的替换 ID 逐个改（对照表见上图）。注意替换建议只是厂商推荐，不是等价保证——大版本换代（比如 gpt-4 → gpt-5.6-sol）一定要跑回归测试，看输出质量和 token 价格变化。
  4. 先用 dry-run：llm-sunset fix --dry-run 预览改写，确认无误再真正落盘；中等置信度的匹配默认会被跳过，别硬开 --include-risky。
  5. 写基线防新增：llm-sunset baseline --write 记录当前状态，之后只报新增的过期引用，团队协作不回潮。

8 天时间，说长不长。模型退役不会等你，404 更不会。花十分钟扫一遍，比半夜被报警叫醒划算多了。
